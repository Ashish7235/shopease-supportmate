# ShopEase Returns and Refunds Policy

**Effective Date:** 1 August 2026

## 1. Overview

ShopEase allows customers to return eligible products within the applicable return period. Refunds are issued after the returned item passes inspection.

## 2. Return Window

| Product Category           | Return Window |
| -------------------------- | ------------- |
| Clothing & Accessories     | 10 days       |
| Footwear                   | 10 days       |
| Home & Kitchen             | 10 days       |
| Beauty Products (unopened) | 7 days        |
| Electronics                | 7 days        |

The return period starts from the delivery date shown in the order tracking record.

## 3. Eligible Return Conditions

A return request is eligible when:

* The request is submitted within the return window.
* The product is unused and undamaged.
* Original packaging, accessories, manuals, and tags are included.
* The item was purchased directly from ShopEase.

## 4. Non-Returnable Items

The following items cannot be returned unless they were received damaged or incorrect:

* Gift cards
* Downloadable software
* Personalized products
* Opened beauty products
* Final-sale items

## 5. Damaged or Incorrect Products

Customers must report damaged or incorrect products within **48 hours of delivery** through the ShopEase support portal. Photos of the product and package may be requested.

## 6. Return Shipping Charges

* **Customer changed mind:** Customer pays return shipping.
* **Damaged product:** ShopEase pays return shipping.
* **Wrong product received:** ShopEase pays return shipping.

## 7. Refund Processing

After the returned item is inspected and approved, refunds are initiated within **5–7 business days**. Prepaid orders are refunded to the original payment method, while Cash on Delivery (COD) orders are refunded through bank transfer.

## 8. Return Rejection

ShopEase may reject a return if the item is used, damaged by the customer, missing accessories, or submitted after the allowed return period.
